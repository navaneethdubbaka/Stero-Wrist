# Surface: Home + Settings shell

Mode: Operate  
Platform: adaptive (React Native / Expo)  
Build path: code-led  
Audience: solo Hermes power user, quick-glance phone status

## Job

Answer “Am I ready?” on Home. Configure Hermes profiles and prefs from Settings when the user chooses (Home-first; soft empty CTA only).

## Direction contract

THESIS: Status reads as a night harbor channel — lit markers along a route — not a SaaS metric dashboard. Refuse card-grid status tiles and purple accent kits.

OWN-WORLD: Deep harbor ink ground (#0B1215) with steel-blue surface bands; lantern states green (ready), amber (degraded/pending), red (error), dim white (off/unknown). Type is system UI sans with strong weight contrast. Density is list-tight, Material-native rows. Signature move: ChannelStrip — a horizontal segmented lantern rail (Assistant | Hermes | TTS | Notifications).

STORY: Visitor sees brand, then channel readiness, then active profile magnitude, then recent placeholders; Settings is a standard stack of native lists.

FIRST VIEWPORT: Top safe-area band with “Stero Wrist”; ChannelStrip immediately below; active profile name large; TTS and notification labels secondary; soft “Set up Hermes” only when zero profiles; gear/settings control in the header trailing edge. No marketing hero.

FORM: Grounded #4 harbor channel markers (night buoy lanterns). seed:10450f5fa977e2b3  
Raises: split-flap discrete cell updates; wayfinding committed coloured shell band; star-atlas magnitude hierarchy for active profile type.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Scope

Phase 0–1 only: Home status, Settings hub, profiles CRUD, webhook editor, assistant/TTS prefs, notification/audio stubs. No live webhook, STT, TTS playback, or FCM.
